Formater des devises en JavaScript

Pour afficher un prix en euros, utilisez Intl.NumberFormat avec la locale fr-FR. Cette méthode gère les séparateurs de milliers, le symbole et la position de la devise selon les conventions locales. Elle est disponible dans tous les navigateurs modernes et dans Node.js.

La propriété minimumFractionDigits permet de fixer le nombre de décimales affichées, ce qui est utile pour les montants monétaires qui doivent toujours afficher deux décimales.
