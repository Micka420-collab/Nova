<h3 align="center">Une idée. Un compagnon. Du concret.</h3>

**NOVA 0.1.0** est la première version installable de l'atelier : tu connectes ta propre clé OpenRouter, tu choisis un modèle dans le catalogue réel (DeepSeek mis en avant) et tu discutes avec Nomi. Tes conversations restent sur ton ordinateur.

> ⚠️ **Préversion (jalon 1).** Pas encore prête pour la production. Les fichiers, le terminal et les missions arrivent au jalon 2.

## Installer

| Système | Fichier | Comment |
| --- | --- | --- |
| **Windows 10/11** (x64) | `NOVA-0.1.0-win-x64.exe` | Lance l'installeur et suis l'assistant. Au premier lancement, Windows SmartScreen peut afficher « Windows a protégé votre ordinateur » : clique **Informations complémentaires** → **Exécuter quand même** (l'application n'est pas encore signée). |
| **macOS** Apple Silicon (M1–M4) | `NOVA-0.1.0-mac-arm64.dmg` | Ouvre le DMG et glisse NOVA dans **Applications**. Au premier lancement : **Ctrl-clic** sur NOVA → **Ouvrir** → **Ouvrir**. Sur macOS 15 et plus : **Réglages Système → Confidentialité et sécurité → Ouvrir quand même**. |
| **macOS** Intel | `NOVA-0.1.0-mac-x64.dmg` | Même procédure. |
| **Linux** (Ubuntu, Debian…) | `NOVA-0.1.0-linux-amd64.deb` | `sudo apt install ./NOVA-0.1.0-linux-amd64.deb`, puis lance **NOVA** depuis tes applications. |
| **Linux** (toutes distributions) | `NOVA-0.1.0-linux-x86_64.AppImage` | `chmod +x NOVA-0.1.0-linux-x86_64.AppImage && ./NOVA-0.1.0-linux-x86_64.AppImage` |

Vérifier un téléchargement : les empreintes SHA-256 sont dans `SHA256SUMS.txt` (`sha256sum -c SHA256SUMS.txt`).

## Premiers pas

1. Crée une clé sur [openrouter.ai/keys](https://openrouter.ai/keys) (idéalement avec une limite de crédit).
2. Colle-la dans NOVA : elle est vérifiée puis rangée dans le **coffre de ton système** (Windows, trousseau macOS, GNOME Keyring/KWallet). Sans trousseau sous Linux, NOVA te le dit et la garde pour la session.
3. Choisis un modèle, écris ton idée.

## Ce que fait cette version

- Conversation en continu avec les modèles d'OpenRouter, arrêt immédiat, relance, reprise après coupure.
- Erreurs expliquées en français (clé refusée, crédits épuisés, trop de requêtes, modèle indisponible…).
- Coût constaté affiché par réponse ; « coût inconnu » quand OpenRouter ne l'a pas communiqué.
- Confidentialité : fournisseurs sans conservation des données par défaut ; clé jamais écrite en clair, jamais dans les journaux.
- Nomi reflète l'état réel : hors ligne, réfléchit, écrit, terminé, erreur. Masquable, mouvement réduit respecté.
- Thèmes Nuit minérale et Papier minéral, navigation au clavier, palette de commandes (Ctrl/⌘+K).

## Vérifié

Tests unitaires (520), parcours complets dans la vraie application et empaquetage réussis en CI sur **Linux, Windows et macOS**. Détail : [docs/STATUS.md](https://github.com/Micka420-collab/Nova/blob/main/docs/STATUS.md).

## Limites connues

- Applications **non signées** (avertissements Windows/macOS ci-dessus).
- Pas de mise à jour automatique : télécharge la version suivante ici.
- Conversation réelle avec une clé OpenRouter : testée sur l'API réelle pour le catalogue et le refus de clé ; le streaming réel reste à confirmer à grande échelle.
